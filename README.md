# HavenCraft Cleaners

Website and launch plan for HavenCraft Cleaners, a cleaning startup serving Westlands, Kilimani, Kileleshwa and Parklands in Nairobi.

| File | What it is |
|---|---|
| `index.html` | Single-file website: Tailwind CSS (CDN), Font Awesome, vanilla JS. Open it in a browser, no build step. |
| `MARKETING.md` | Local SEO and marketing launch manual, plus a pre-launch checklist. |

## Site features

- Service tabs with KES pricing, driven by one `CATEGORIES` data object in the script (edit prices there, tabs and estimator both update).
- Instant cost estimator with quantity steppers, square-foot input for wall-to-wall carpet, area-based transport fee and one-click presets.
- Booking modal that turns the form (and estimate, if any) into a pre-filled WhatsApp message.
- Sticky "Book via WhatsApp" button, before/after slider, FAQ, reviews.
- SEO title/description, OpenGraph/Twitter tags and `HouseCleaningService` JSON-LD.

## Before going live

See the checklist at the end of `MARKETING.md`: real phone number, domain, OG image, real reviews and photos.
